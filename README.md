# DevSprite.io

A landing page for DevSprite.io, focused on helping local businesses build their online presence.

<p align="center">
  <img src="assets/img/banner.png" alt="DevSprite.io banner" width="100%">
</p>


## Overview

This site showcases DevSprite.io's services, process, collaboration examples, and contact call-to-action for local business clients.

## Features

- Responsive hero section with collaboration carousel
- Services section
- Process section
- Contact call-to-action
- Minimal footer

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` - main page markup
- `assets/css/styles.css` - site styles
- `assets/js/main.js` - interactive behavior
- `assets/img/` - images and branding assets

## Local Preview

Open `index.html` in your browser.

## Customization

You can update:
- hero text in `index.html`
- colors and layout in `assets/css/styles.css`
- carousel behavior in `assets/js/main.js`
